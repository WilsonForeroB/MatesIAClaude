# MatesIAClaude
Artefactos interactivos de Claude para explicar Matematicas Basicas

## Pizarra matemática

`Pizarra/pizarra-matematica.html`: pizarra para dar clase con el estilo MatIA. Escribe fórmulas con atajos (MathLive), matrices y sistemas desde plantillas, calcula con fracciones exactas (`A·B`, `A^{-1}`, `det A`…), aplica Gauss o Gauss-Jordan paso a paso, dibuja a mano alzada y trabaja con varias páginas. Necesita conexión para cargar MathLive desde CDN. Pulsa `?` dentro de la pizarra para ver todos los atajos.
