# MatesIAClaude
Artefactos interactivos de Claude para explicar Matematicas Basicas

## Pizarra matemática

[`pizarramatia/pizarra.html`](pizarramatia/pizarra.html): pizarra para dar clase con el estilo MatIA. Escribe fórmulas con atajos, matrices y sistemas, desarrollos alineados por el «=» con la explicación de cada paso, más de 30 operaciones paso a paso (Gauss, determinantes, Cramer, autovalores, ecuaciones, fracciones, polinomios, combinatoria, tablas de verdad, conjuntos, derivadas y gráficas), dibujo a mano alzada y un **historial** de clases en JSON (carpeta `pizarramatia/historial`, que no se sube a Git). Cómo funciona: [`pizarramatia/README.md`](pizarramatia/README.md).
